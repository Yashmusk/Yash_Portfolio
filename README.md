# Yash Agarwal — Product Portfolio

Personal portfolio for APM / Product Manager roles: experience, a product case study (Sahi), projects, skills and resume.

Built with React, Vite, TypeScript, Tailwind CSS, Framer Motion and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The output goes to `dist/`. `vercel.json` and `public/_redirects` handle page routing on Vercel and Netlify.

## Updating content

All content lives in `src/data/`:

- `profile.ts` — name, contact links, education, achievements
- `experience.ts` — roles and product work
- `caseStudies.ts` — the Sahi case study
- `projects.ts` — projects, metrics and targets
- `skills.ts` — product skills and technical foundation

Resume: `public/Yash_Agarwal_Resume.pdf`. Photo: `public/yash.jpg`.
